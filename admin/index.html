Publishing flow

3 steps
  1. DraftTulis di editor visual, unggah gambar, atur slug.
  2. GenerateSistem menulis file HTML statis di root project.
  3. AppearKartu baru masuk paling atas di halaman /blog/.

Safeguards

  • WordPress HTML lama tidak di-overwrite.
  • Delete menghapus file HTML dari server.
  • Upload gambar ke wp-content/uploads, max 500KB.
  • Backup listing tetap ada di /blog/managed/.
